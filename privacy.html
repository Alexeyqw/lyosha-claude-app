Privacy Policy — Lyosha Claude

Last updated: November 22, 2026

What the app is

Lyosha Claude is a personal application used only by the owner of the YouTube channel @logunotube to manage that channel.

Data the app accesses

With the owner's permission through Google OAuth, the app uses the YouTube Data API and YouTube Analytics API to read the owner's channel and video statistics, read analytics reports, and upload the owner's own videos.

How data is used and stored

Data is used only to show statistics to the owner and to publish his videos. OAuth tokens and data are stored locally on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at https://myaccount.google.com/permissions. Locally stored data can then be deleted by the owner.
